Nyrox Labs Publisher

A private desktop tool that publishes short science and technology videos to the Nyrox Labs YouTube channel and reads that channel's own statistics.

What it does

  • Uploads finished YouTube Shorts produced on the owner's computer to the owner's own channel.
  • Reads view, retention and engagement statistics for those videos, so the tool can learn which topics and formats work.
  • Runs only on the channel owner's computer. It is not offered to the public, and no other user can sign in to it.

Google account access

The tool asks for these Google permissions, and uses them only for the channel owner's own channel:

ScopeWhy
youtube.uploadUpload new Shorts to the channel.
youtube.readonlyCheck upload status, privacy and basic counts of the channel's videos.
yt-analytics.readonlyRead retention and average view duration for the channel's videos.
